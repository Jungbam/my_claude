# Design Artifact Templates

> 디자인 산출물 골격 템플릿 SSOT. `design-artifact-layout.md`(구조/규칙)에서 이관한 템플릿 본문 + design-system-agent 토큰 템플릿(tokens.json·CSS 출력·컴포넌트 문서)을 합본·dedup했다. 필요한 산출물 작성 시 해당 §만 offset/limit로 Read한다.

## 템플릿 골격

### preview/index.html 최소 구조

```html
<!DOCTYPE html>
<html lang="ko" data-theme="light">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>{프로젝트명} — Design Preview</title>
  <link rel="stylesheet" href="../tokens/tokens.css">
  <link rel="stylesheet" href="shared/styles.css">
</head>
<body>
  <!-- 화면 목록: screens/ 하위 iframe 또는 section으로 구성 -->
  <main>
    <section id="screen-home">
      <!-- home 화면 마크업 -->
    </section>
  </main>
</body>
</html>
```

**필수 요소**:
- `<html data-theme="light">`: 다크모드 override를 위한 `data-theme` 속성
- `<link rel="stylesheet" href="../tokens/tokens.css">`: tokens.css **반드시** 첫 번째 link
- semantic HTML5 (`main`, `section`, `nav`, `header`, `footer` 등)
- `lang="ko"` 또는 해당 언어 코드 (접근성 필수)

#### tokens.json (Style Dictionary 호환)

Style Dictionary 표준 포맷으로 생성하여 빌드 파이프라인 연동을 지원한다. 출력: `tokens/tokens.json`. (dedup: tokens.css/tokens.ts 골격은 위 §들이 정본)

```json
{
  "color": {
    "brand": {
      "500": {
        "category": "color",
        "type": "brand",
        "value": "#3b82f6",
        "comment": "Primary brand color"
      }
    },
    "primary": {
      "category": "color",
      "type": "semantic",
      "value": "{color.brand.500}",
      "comment": "Primary interactive color"
    }
  },
  "space": {
    "md": {
      "category": "spacing",
      "type": "semantic",
      "value": "16px"
    }
  },
  "motion": {
    "fast": {
      "category": "motion",
      "type": "duration",
      "value": "150ms"
    }
  }
}
```

필드 구성: `category` / `type` / `value` (Style Dictionary 표준), `comment` 권장.

#### 컴포넌트 문서 템플릿

design-system-agent가 컴포넌트 문서화 시 사용하는 골격 (Purpose/Anatomy/Variants/Props/Accessibility/DO·DON'T). 아래는 인용 예시(indented code block — 실제 문서에는 헤딩 레벨을 문맥에 맞게 조정):

    ## [ComponentName]

    ### Purpose
    [컴포넌트의 사용 목적과 주요 사용 맥락]

    ### Anatomy
    [컴포넌트 구성 요소 설명]

    ### Variants
    | Variant | 설명 | 사용 맥락 |
    |---------|------|---------|

    ### Props
    ```typescript
    interface ComponentProps {
      /** 설명 */
      variant: 'primary' | 'secondary';
    }
    ```

    ### Accessibility
    - 키보드 네비게이션: [설명]
    - ARIA 속성: [설명]

    ### DO / DON'T
    - DO: [올바른 사용법]
    - DON'T: [잘못된 사용법]
